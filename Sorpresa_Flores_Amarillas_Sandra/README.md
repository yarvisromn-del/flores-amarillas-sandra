# Para Sandra Sarai 💛🌻

Una web romántica interactiva de flores amarillas, hecha con HTML, CSS y JavaScript. No necesita instalar dependencias ni ejecutar un build.

## Probar en tu computadora

1. Descomprime el proyecto.
2. Abre `index.html` en el navegador.

## Publicar gratis en Vercel

### Opción recomendada: GitHub + Vercel
1. Crea un repositorio en GitHub y sube los archivos de esta carpeta (`index.html`, `style.css`, `script.js`, `vercel.json` y `README.md`).
2. Entra a https://vercel.com e inicia sesión.
3. Selecciona **Add New → Project** e importa el repositorio.
4. Como es una web estática, deja el framework como **Other** y no configures Build Command ni Output Directory.
5. Pulsa **Deploy**. Vercel te dará un enlace para compartir.

## Personalizar
- Los mensajes están en `index.html` y `script.js`.
- Los colores, el diseño y las animaciones están en `style.css`.
- La web funciona en celular y computadora. Las fuentes de Google Fonts requieren internet; si no cargan, se usarán fuentes alternativas.
